# TeamPad — Roadmap

Updated: 2026-01-23

## Phase 1: Reliability & Polish
- Disk cache (AsyncStorage) for cold-start speed
- Inline retry banners (no full-screen errors)
- Refresh animations that don’t block UX

## Phase 2: Collaboration Depth
- Mentions + mention notifications UI
- Read states / last read marker
- Invite management surface (pending invites list)

## Phase 3: Notes Power
- Tags UI + filters
- Public note sharing (expiry)
- Attachments in notes

## Phase 4: Differentiators
- Voice notes
- Focus mode
- Team pulse

## Phase 5: Monetization
- Billing + plan gates
- Usage dashboards
